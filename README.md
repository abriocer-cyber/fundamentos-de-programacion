## Descripción del proyecto

Este repositorio contiene una colección de ejercicios prácticos desarrollados durante la asignatura de Fundamentos de Programación, con el propósito de aplicar los conocimientos adquiridos sobre lógica de programación, estructuras de control y desarrollo de algoritmos.

## Ejercicios desarrollados

### Ejercicio 1
Descripción: Este ejemplo muestra en pantalla los números pares del 2 al 20, utilizando una estructura repetitiva Mientras. .

Archivo: `ejercicio-1/ejercicio_1.cpp`

### Ejercicio 2
Descripción: Este ejercicio solicita al usuario un número entero positivo N y calcula la suma de todos los números enteros desde 1 hasta N, utilizando una estructura repetitiva Mientras. .

Archivo: `ejercicio-2/ejercicio_2.cpp`
